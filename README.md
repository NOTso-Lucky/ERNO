# ERNO

ERNO is an AI-powered Rubik's Cube motion recognition system that aims to interpret cube movements as commands and eventually as a visual communication language.

## Vision

The long-term goal of ERNO is to allow a Rubik's Cube to function as an input device. By tracking cube motion through a webcam, ERNO will recognize moves and sequences of moves and translate them into meaningful commands, actions, or language.

## Current Status
